# 최단 풀이 (Fastest Route)

수학 문제를 **직접 입력하거나 사진으로 올리면**, 실전에서 가장 빠른 풀이 경로를
단계별로 보여주는 웹앱입니다. 정석 풀이가 아니라 "시험장에서 시간을 아끼는 길"을
찾아주는 것이 목적입니다.

- 문제 입력: 텍스트 · 사진 업로드 · 드래그앤드롭 · 클립보드 붙여넣기(Ctrl+V) · 모바일 카메라
- 결과: 핵심 관찰 한 줄 → 단계별 풀이(수식은 KaTeX 렌더) → 최종 답 → 자주 하는 실수 / 정석이 느린 이유
- 최근 푼 문제 20개는 브라우저에 자동 저장됩니다 (`localStorage`, 서버에는 남지 않음)

### 정확도를 위해 넣은 장치

**응답을 JSON으로 주고받지 않습니다.** LaTeX는 백슬래시가 많아 JSON 문자열과 충돌합니다.
`\lim`, `\infty` 는 파싱 자체를 실패시키고, `\to`, `\frac` 은 각각 탭 문자와 폼피드로
조용히 변질됩니다. 후자가 특히 위험한데, 오류 없이 수식만 망가진 채 풀이가 진행됩니다.
그래서 이스케이프가 필요 없는 `@@블록` 구분자 형식을 씁니다. (`server/index.js` 프롬프트,
`src/App.jsx`의 `parseBlocks`)

**푸는 단계와 읽는 단계를 나눕니다.** 한 번에 처리하면 잘못 읽어도 알 방법이 없습니다.

1. **영역 지정** — 사진 위에서 문제 하나를 드래그로 지정합니다. 시험지에는 문제가 여러 개
   찍히는 경우가 많아, 이 단계가 오답의 가장 큰 원인을 없애줍니다.
2. **전처리** — 긴 변을 1568px(비전 모델이 내부적으로 재축소하지 않는 상한)에 맞춥니다.
   작은 이미지는 최대 2배까지 키웁니다. 해상도가 늘어도 정보가 생기진 않지만 글자가 커지면
   판독률이 확실히 오릅니다. 밝기 분포를 펴서 종이 그림자를 걷어내되, 어두운 쪽은 0.3%만
   잘라냅니다(글자는 전체 픽셀의 몇 퍼센트뿐이라 양쪽을 똑같이 자르면 글자가 날아갑니다).
3. **판독 전용 호출** (`/api/read`) — 풀지 않고 옮겨 적기만 합니다. 프롬프트에 한국 시험지
   관례(① ② ③, (가)(나), [4점]), 좌극한/우극한 방향, 등호 포함 여부, 열린구간/닫힌구간,
   "단, ~이다" 단서 누락 금지를 명시했습니다.
4. **확인 화면** — 읽은 내용을 고칠 수 있고, 수식으로 렌더된 미리보기를 함께 보여줍니다.
   판독이 불확실하면 경고를 띄웁니다.
5. **풀이 호출** (`/api/solve`) — 확정 텍스트를 정본으로 삼되 **원본 사진도 함께** 보냅니다.
   그래프·도형 정보가 텍스트 변환에서 사라지기 때문입니다.

**직접 입력도 같은 확인 단계를 거칩니다.** 손으로 친 수식은 해석이 갈립니다
(`1/2x` 가 $\frac{1}{2}x$ 인지 $\frac{1}{2x}$ 인지). 정규화 후 렌더된 모습을 보여주고,
애매한 지점은 무엇이 애매한지 짚어줍니다. 수식 입력 팔레트와 실시간 미리보기도 있습니다.

**풀이는 정확성이 속도보다 우선입니다.** 모델이 화면에 보이지 않는 `@@SCRATCH` 칸에서
충분히 계산하고 검산(원식 대입, 특수값 확인, 선택지 대조)한 뒤 답을 씁니다. 검산이 어긋나면
다시 계산하도록 지시했습니다. 확신도가 낮으면 답 아래에 검산 권고가 표시됩니다.

### 함께 나오는 것들

**상위 교육과정 풀이** — 같은 문제를 대학 과정 도구로 푸는 방법을 함께 보여줍니다.
테일러 전개, 평균값 정리, 급수 수렴판정, 선형대수, 생성함수, 모듈러 산술 같은 것들입니다.
대상 독자를 "고등학교 미적분 선택자"로 못박아 두어서, 새 도구가 나올 때마다 그게 무엇인지
한 줄로 먼저 설명하고 고교 풀이와 어떻게 연결되는지 짚어줍니다. 필요한 선행 지식은
카드로 따로 정리해 보여줍니다. 마땅한 상위 관점이 없는 문제면 이 부분은 나오지 않습니다.
입력 화면의 체크박스로 끌 수 있습니다 (끄면 응답이 더 빠릅니다).

**진법 풀이** — 수열 문제에서 인덱스가 $a_{2n}$, $a_{2n+1}$ 처럼 갈라지면 그 수열은 사실
인덱스의 2진 표현을 따라가는 구조입니다. $a_{3n}$, $a_{3n+1}$, $a_{3n+2}$ 라면 3진법입니다.
이런 구조가 잡히면 자릿수를 읽어 바로 답을 내는 풀이를 함께 보여줍니다.
해당하지 않는 문제에는 나오지 않습니다.

**항 매핑 트리** — 위와 같은 수열은 트리로 그려집니다. 인덱스 $k$ 의 자식은 2진법이면
$2k$, $2k+1$, 3진법이면 $3k$, $3k+1$, $3k+2$ 입니다. 부모는 언제나 인덱스를 진법으로 나눈
몫이라서, 트리를 타고 내려가는 길이 곧 인덱스의 진법 표현이 됩니다. SVG로 직접 그리며,
자식이 부모 아래에 오도록 배치합니다.

## 1. Render에 배포하기

이 저장소에는 `render.yaml`이 포함되어 있어 설정을 자동으로 읽어갑니다.

### 방법 A — Blueprint로 한 번에 (권장)

1. 이 폴더를 GitHub 저장소에 올립니다.
2. [dashboard.render.com](https://dashboard.render.com) → **New → Blueprint**
3. 저장소를 선택하면 `render.yaml`을 읽어 설정이 자동으로 채워집니다.
4. `ANTHROPIC_API_KEY` 값을 입력하라는 항목이 뜹니다. 발급받은 키를 넣습니다.
   (`sync: false`로 지정되어 있어 저장소에 키가 남지 않습니다)
5. **Apply** → 몇 분 뒤 `https://fastest-route-math.onrender.com` 형태의 주소가 생깁니다.

### 방법 B — 웹 서비스로 직접 생성

1. **New → Web Service** → 저장소 선택
2. 아래대로 입력합니다.
   - Runtime: `Node`
   - Build Command: `npm install && npm run build`
   - Start Command: `npm start`
   - Health Check Path: `/api/health`
3. **Environment** 탭에서 환경변수를 추가합니다.
   - `ANTHROPIC_API_KEY` = 발급받은 키
   - `ANTHROPIC_MODEL` = `claude-sonnet-4-6` (선택)
4. **Create Web Service**

> **Render 사용 시 알아둘 점**
> - 포트는 Render가 `PORT` 환경변수로 자동 주입하며, 서버가 이를 그대로 사용합니다.
>   직접 설정할 필요가 없습니다.
> - 무료 플랜은 15분간 요청이 없으면 잠들고, 다음 첫 요청이 깨우는 데 30초쯤 걸립니다.
>   학생들이 바로 쓰게 하려면 유료 플랜(Starter)을 쓰거나 외부에서 주기적으로
>   `/api/health`를 호출해 깨워두세요.
> - 사진 한 장 기준 응답까지 10~25초 정도 걸립니다. 무료 플랜에서도 타임아웃 문제는 없습니다.

## 2. 로컬에서 실행하기

```bash
npm install

cp .env.example .env
# .env 를 열어 ANTHROPIC_API_KEY 를 채웁니다

npm run build
npm start
```

`http://localhost:3000` 접속. 프론트를 고치면서 자동 재빌드하려면 `npm run dev`.


## 4. 손보고 싶을 때

- **풀이 스타일을 바꾸려면** `server/index.js`의 `SOLVE_SYSTEM` 프롬프트를 고칩니다.
- **판독 규칙을 바꾸려면** 같은 파일의 `READ_SYSTEM`, 직접 입력 해석은 `NORMALIZE_SYSTEM`을
  고칩니다. 자주 쓰는 교재의 표기 관례를 추가하면 정확도가 더 올라갑니다.
  세 프롬프트 모두 `@@블록` 형식은 그대로 두어야 합니다. 형식을 바꾸면
  `src/App.jsx`의 `parseBlocks`도 함께 고쳐야 합니다.
- **더 어려운 문제를 자주 다룬다면** `.env`의 `ANTHROPIC_MODEL`을 상위 모델로 바꾸세요.
  킬러 문항 정답률에서 차이가 큽니다.
- **수식 입력 버튼을 늘리려면** `src/App.jsx` 상단의 `SYMBOLS` 배열에 추가합니다.
  `[라벨, 넣을 LaTeX, 커서를 되돌릴 칸 수]` 형식입니다.
  입력 예시 칩은 같은 파일의 `EXAMPLES` 배열입니다.
- **일반인이 쓰는 표기를 더 알아듣게 하려면** `server/index.js`의 `NORMALIZE_SYSTEM`에
  있는 표기 예시 목록에 추가하세요. ("x제곱", "2분의 1", "리미트 x가 0으로 갈 때" 같은 것들)
- **상위 과정 풀이에서 다루는 도구를 조정하려면** `SOLVE_SYSTEM`의 `[상위 교육과정 풀이]`
  항목에 있는 도구 목록을 고칩니다.
- **트리 모양을 바꾸려면** `src/App.jsx`의 `TermTree` 안 `stepX`, `rowH`, `nodeW` 값입니다.
- **색을 바꾸려면** `src/styles.css` 맨 위 `:root`의 변수만 바꾸면 전체 톤이 따라옵니다.
- **사진 해상도**는 `src/App.jsx`의 `MAX_DIM`(기본 1568px)입니다. 이 값은 비전 모델이
  내부적으로 재축소하지 않는 상한이라 더 키워도 효과가 없고 비용만 늘어납니다.
- **대비 보정이 과하다면** 같은 파일 `stretchContrast`의 `cut`(양 끝 2%)이나 `scale` 상한(3)을
  낮추세요. 연필로 흐리게 쓴 문제를 다룰 때 조정이 필요할 수 있습니다.
- **기록 보관 개수**는 `LEDGER_LIMIT`(기본 20개)입니다.

## 5. 운영 시 참고

- 이 앱은 로그인이 없어서 주소를 아는 사람은 누구나 쓸 수 있고, 호출량만큼 API 비용이
  나갑니다. 학원이나 반 단위로 공개하실 거라면 간단한 비밀번호나 호출 횟수 제한을
  붙이시는 걸 권합니다.
- 답이 항상 맞다고 보장할 수 없습니다. 화면 하단에도 안내가 있지만, 학생에게 배포할 때
  "채점 기준이 아니라 접근법 참고용"이라고 함께 알려주세요.
